- 报错链：`project.godot [editor_plugins]` 启用插件 + `.godot/extension_list.cfg` 记录了
  `res://addons/godot-minigame/godot-minigame.gdextension` → 每次启动（含非编辑器运行）都尝试加载
  `bin/windows/...dll`，缺失即 ERROR。只改 gdextension 内容或改名都无效，路径来自 extension_list.cfg。
- 最终做法（插件休眠）：`addons/godot-minigame/.gdignore`（空文件）+ 移除 `[editor_plugins]` + 删除
  `.godot/extension_list.cfg`。此时编辑器和运行都零报错，编辑器也不会再把该扩展写回缓存。
- 恢复：删 `.gdignore` → 打开编辑器（会重新登记扩展）→ 项目设置-插件勾选 Godot Minigame。
- 前提仍是 DLL：`winget install Microsoft.VisualStudio.2022.BuildTools`（VCTools 工作负载）+
  `git clone --recursive` 仓库 + `build_win.bat` → 拷 `demo/addons/godot-minigame/bin/windows/*.dll`。

## 修 wx 登录：get_interface 在微信里拿不到接口（同日）

- 现象：开发者工具里运行正常，点登录报
  `ERROR: No interface '__GodotWx' registered. at get_interface (javascript_bridge_singleton.cpp:305)`，
  随后走模拟登录。
- 原因：微信小游戏的 `window` 是 weapp-adapter 伪造对象，与真正全局 `globalThis`/`GameGlobal` 不同；
  `JavaScriptBridge.get_interface()` 内部按全局名查找，和 eval 里挂载的对象不是同一个。
  （仓库自带的 `wechat-bridge-test.js` 同样在处理 window≠globalThis 这个坑。）
- 改法：`wx_api.gd` 彻底不用 get_interface / create_callback，改为 **eval + 轮询**：
  - `JS_BOOT` 把 `__GodotWx` 同时挂到 GameGlobal / globalThis / window / self 上；
  - 每次调用拼成 `JS_BOOT + "\n" + '__gwxCall("xxx")'` 一次 eval，函数声明同作用域可用；
  - `probe/login/poll/toast` 四个动作，GDScript 每 150ms 轮询 `poll`，10 秒超时；
  - `probe()` 返回 hasWx / windowIsGlobal / hasGameGlobal / rootCount，失败时把诊断写进状态栏。
- 验证：Node 模拟「window≠globalThis、wx 在真全局」跑通成功/失败/无 wx 三分支；桌面 headless 回归 mock 登录正常。
- 桌面端 `JSON.parse_string("")` 会报错刷屏，已加 `_parse()` 空串保护。

## 桥接改版：改用宿主 JS 文件 + get_interface（同日，第二轮）

- 实测 `[Wx] probe = { "raw": "" }`：这个自定义引擎构建里 `JavaScriptBridge.eval()` 不回传值
  （api.cpp 里有 `#if !defined(WEB_ENABLED) || !defined(JAVASCRIPT_EVAL_ENABLED)` 的桩实现，
  桩里 eval 返回空 Variant）。所以 eval 注入方案走不通。
- 新方案（与模板访问 `GODOTSDK` 同路）：
  1. `wechat_test_wxgame/wx-bridge.js`：在宿主作用域定义 `__GodotWx`（probe/login/poll/toast），
     挂到 GameGlobal + globalThis + window；
  2. `wechat_test_wxgame/game.js` 第一行 `import './wx-bridge'`（实测插件重新导出不会覆盖 game.js，
     也不会删我们加的 js 文件）；
  3. `wx_api.gd` 改用 `JavaScriptBridge.get_interface("__GodotWx")` + 方法调用 + 150ms 轮询。
- **导出过滤坑**：`exclude_filter="addons"` 匹配不到子目录，必须写 `addons/*,build/*`。
  之前一次导出把 `addons/` 下 328 个文件（含 1.4MB 的 godot_ai）全打进 pck，包体 682KB → 2.1MB。
- 第三方插件 `addons/godot_ai`（MCP 调试用，17:30 自动安装）会往 `[autoload]` 塞 `_mcp_game_helper`；
